Shipping & Delivery Policy

Last updated: 19 September 2026

Digital product, no physical shipping

GyaanPe plans and courses are digital. Nothing is shipped to a physical address and there are no shipping charges.

How and when it is delivered

Your unlock code appears on the screen immediately after successful payment, usually within a few seconds. You can copy the code or send it to yourself on WhatsApp from that screen.

The code is also kept in the payment page on the same device, under “codes bought from this phone”.

If you do not receive your code

If your money was debited but no code appeared, refresh the payment page first; the code is fetched again automatically. If it still does not appear, email gyaanpe.support@gmail.com or WhatsApp +91 70081 12031 with your Razorpay Payment ID. We will send your code within 1 working day, or refund you in full.

Using the code

Open GyaanPe, go to “Code se unlock karein” and enter the code. One code works on up to 3 devices.
